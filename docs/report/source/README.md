# IEEE report source

The editable LaTeX source and both figures used by the six-page project report
are included here. Upload all four files in this folder to an Overleaf project,
select `AutoGrader_IEEE_Conference.tex` as the main document, and compile with pdfLaTeX.
The `IEEEtran` class is required.

On Ubuntu with TeX Live installed, run from this folder:

```sh
pdflatex AutoGrader_IEEE_Conference.tex
pdflatex AutoGrader_IEEE_Conference.tex
```

The report describes the implemented prototype and its limitations. The project
team is **Team Everest**, Computer Science & Engineering, IIT Patna.
